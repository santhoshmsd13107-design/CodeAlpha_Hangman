Hangman Game using Python

About the Project

This is a simple text-based Hangman game developed using Python. The player must guess a hidden word one letter at a time.

Features

- Contains 5 predefined words.
- Allows 6 incorrect guesses.
- Displays guessed letters.
- Checks correct and incorrect guesses.
- Displays win or game-over messages.

Technologies Used

- Python
- Random Module
- Lists
- While Loop
- If-Else Conditions
- Strings

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:

python hangman.py
